MediCare Clinic Secure Network

Designed a secure multi-site healthcare network with segmented VLANs, ACLs, IPSec VPNs and a DMZ zone-based firewall.

  • Cisco Packet Tracer
  • VLANs
  • ACLs
  • IPSec VPN
  • Zone-Based Firewall
  • RADIUS
  • HTTPS
View Project ▸
Challenge

Design a secure multi-site network for a healthcare provider (clinics, labs, pharmacies and IoT medical devices), mapping ransomware, DDoS and data-theft threats against downtime and revenue impact.

Environment

Simulated multi-site topology in Cisco Packet Tracer.

What I Built

VLAN segmentation (admin, HR, doctors, IoT, labs, pharmacy, guests, DMZ, wireless, branch) and ACLs limiting ICMP/host discovery to reduce the attack surface. Configured an IPSec site-to-site VPN, HTTPS-only EMR access, and DMZ zone-based firewall policies controlling flows between internal networks, the DMZ and external partners. Hardened email and remote access by placing servers in a DMZ and documenting SPF, DKIM, DMARC, MFA and secure-protocol practices.

Security Concepts

Network segmentation, ACLs, IPSec VPN, zone-based firewalls, DMZ, defence-in-depth, email security (SPF/DKIM/DMARC/MFA).

Result

A documented secure network design that reduces the attack surface on clinical systems (CSCI368).

What I Learned

How to map threats to business impact and apply segmentation as a practical control.

Security Automation / ML

Password Strength Advisor — ML for Password Security

Trained an ML classifier to grade password strength, reaching ~87.7% accuracy with safety-first downgrade logic.

  • Python
  • scikit-learn
  • Logistic Regression
  • TF-IDF
  • pandas
  • numpy
View Project ▸
Challenge

Build an AI-powered password strength classifier (weak / medium / strong) that is useful and safe for real users.

Environment

Python with scikit-learn, trained on 50,000+ synthetic and common leaked passwords.

What I Built

Engineered character-level TF-IDF features with a one-vs-rest multi-class Logistic Regression model, achieving ~87.7% accuracy vs a 70–75% baseline. Added leaked-password checks and conservative downgrade logic that prioritises user safety.

What I Tested

Evaluated with confusion matrices, precision, recall, F1 and 5-fold cross-validation; benchmarked against Random Forest, SVM and neural-network models.

Security Concepts

ML for security, feature engineering, model evaluation, safety-first design.

Result

A working classifier that outperforms the baseline while deliberately erring toward caution (CSIT375).
